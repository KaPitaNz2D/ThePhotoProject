# The Photo Project — สรุประบบทั้งหมด (ย่อ)

> เอกสารนี้เป็นเวอร์ชันย่อ อ่านเร็ว เข้าใจง่าย ดูรายละเอียดทางเทคนิคเต็มๆ ได้ที่ [README_DETAILED.md](README_DETAILED.md)
>
> **อัปเดตล่าสุด:** 2026-10-22

## เกมนี้คืออะไร

เกมสำรวจธรรมชาติมุมมองบุคคลที่ 1/3 — เดินสำรวจป่า **ถ่ายรูป** สัตว์/พืชที่เจอ เก็บเข้า **สมุดบันทึก (Journal)** และคุยกับ **NPC** เพื่อรับ/ส่งเควส

## ระบบหลักที่มีอยู่ตอนนี้

| ระบบ | ทำอะไร |
|---|---|
| **State Manager** | ตัวกลางคุม "สถานะเกม" (เดินปกติ/ถ่ายรูป/คุย NPC/เปิด Journal/เปิด Storage/พัก) ระบบอื่นทุกระบบเช็คจุดนี้ก่อนว่าตอนนี้ทำอะไรได้บ้าง |
| **Player Movement & Camera** | เดิน/วิ่ง/กระโดด/ย่อ (ตอนอยู่โหมดถ่ายรูปยังเดินได้ ช้าเท่าตอนย่อ ตามทิศที่กล้องมองอยู่) พร้อม Foot IK (เท้าเหยียบพื้นจริง) และกล้องบุคคลที่ 3 แบบสลับไหล่ซ้าย-ขวาได้ (กล้องซูมเข้ามาเองเมื่อโดนบ้านหรือพื้นบัง ไม่ทะลุกำแพง) |
| **Photography (ถ่ายรูป)** | กดเข้าโหมดถ่ายรูป เล็งเป้า ซูมเข้า-ออก เอียงกล้องด้วย Q/E (ไม่เกิน 60° แต่ละด้าน) ยก/ลดกล้องด้วย Space/Left Ctrl (ปรับระยะสูงสุดได้) ตัวละครหันตามทิศที่กล้องมอง กดชัตเตอร์ถ่าย แล้วบันทึกเป็นไฟล์ภาพ พร้อมเช็คว่าถ่ายติดสัตว์/พืชตัวไหนบ้าง — หน้าจอกล้องเป็นกรอบช่องมองภาพ 4 มุมชิดขอบจอ + กรอบโฟกัสกลางจอ (เปลี่ยนเป็นสีเขียวเมื่อเล็งโดนสิ่งที่ถ่ายได้) + แถบซูมด้านบน + แผงสอนปุ่มฝั่งขวา (กด Tab ซ่อน/โชว์) |
| **Creature AI (พฤติกรรมสัตว์)** | สัตว์มี AI แบบ Behavior Tree 3 ชั้น: **Normal** (ยืน/หันมองข้างๆ, เดินตามโหนด, ก้มกินหญ้าบนพื้นหญ้า — ตอนกินการรับรู้แคบลงครึ่งหนึ่ง) → **Confuse** (ได้ยินเสียงชัตเตอร์หรือเราเดินเข้าใกล้ → หยุดนิ่งงง → หันหัวมองซ้าย-ขวา) → **Engage** (เห็นเรา → Alert จ้องหน้า ถ้าเรายืนนิ่งนานเกินไป/เข้าใกล้/เข้าโหมดกล้อง/วิ่ง → Run วิ่งหนี) — วิ่งเข้าใกล้ในระยะใกล้ๆ กวางหนีทันทีไม่ผ่านขั้นตอนอื่น หลบในท่าย่อจะทำให้สัตว์มองเห็นเราได้ยากขึ้น — สัตว์เอียงตัวตามความชันพื้นเวลาขึ้น/ลงเนิน และตอนเดินเล่น สัตว์จะเดินไปมาระหว่าง "โหนด" จุดเดินที่สร้างอัตโนมัติจาก NavMesh (ปรับระยะห่างโหนดได้) แทนการสุ่มจุดอิสระ — มีระบบ Spawn/Despawn สัตว์: เกิดในพื้นที่ที่กำหนดเมื่อผู้เล่นเดินเข้าไปอยู่ในพื้นที่นั้น (สัตว์ร้อง 1 ครั้งตอนเกิด)และตัวสัตว์อยู่นอกสายตาผู้เล่น (มีข้อความเตือน) และหายไปเมื่อวิ่งหนีไปไกลพอและพ้นสายตา |
| **Journal (สมุดบันทึก)** | สมุดสันห่วงมีแท็บ **Tasks** (เควสที่รับจาก NPC แล้ว ติ๊กเมื่อเสร็จ) / **Contents** / **Plants** (ดอกไม้+เห็ด) / **Animals** — กริด 3x3 ก่อนถ่ายรูปโชว์แค่เงาดำ+ที่อยู่ ถ่ายติดแล้วปลดล็อกรูปจริง **เลือกเปลี่ยนรูปประจำหน้าได้** จากภาพใน Storage ที่มีสิ่งนั้นอยู่ ส่วนข้อมูลเพิ่มเติมโชว์ต่อเมื่อกลับไปคุยกับ NPC จนได้ฟังเรื่องนั้นแล้ว — ◀ / Esc ย้อนขึ้นทีละชั้นจนถึงหน้า Tasks แล้วปิดสมุด ▶ พลิกหน้าถัดไปเมื่อมีหลายหน้า เปิดครั้งหน้าเจอหน้าล่าสุด (ใช้ Sprite + ฟอนต์ Itim ของ UI Designer แล้ว ปุ่มนูนตอนวางเมาส์ จางลงตอนกด เหลือปุ่มเปลี่ยนรูป/กรอบรูป/ลูกศรกางแถบที่ยังเป็น Placeholder) มีเสียงพลิกหนังสือตอนเปิด/ปิด/เปลี่ยนหน้า |
| **Save / Load (เซฟข้ามการปิดเกม)** | รูปที่ถ่าย, เควส, ข้อมูลที่ NPC เคยเล่า, Journal (รูปประจำหน้า/หน้าที่เปิดค้าง), รูปบนบอร์ด และตัวแปรในบทสนทนา (เช่นเคยคุยแนะนำตัวแล้ว) **เซฟอัตโนมัติทันทีที่เปลี่ยน** ลงเครื่อง ปิดเกม/หยุด Play แล้วเปิดใหม่ทุกอย่างยังอยู่ (`SaveSystem` → โฟลเดอร์ `Save/`, `Photos/`, `JournalPhotos/` ใน persistentDataPath) — ล้างเซฟได้จากปุ่ม Reset ในเมนูหลัก หรือปุ่ม R |
| **Quest & Dialogue** | คุยกับ NPC ชื่อ **Mia** (ผู้ดูแลอุทยาน) ผ่านระบบ Yarn Spinner รับเควส "ไปถ่ายรูป X มา" อัตโนมัติ (ไม่มีตัวเลือกรับ/ไม่รับ) กลับมาคุยอีกครั้งเพื่อส่งเควส — เควสกวาง `deer_01` → ส่งเสร็จได้เควสมูส `moose_01` ต่อทันที (มูสล็อกจนกว่ากวางเสร็จ) — บทพูดโชว์เป็น**บับเบิลคำพูด**ลอยเหนือหัวคนพูด (NPC/ผู้เล่น, `DialogueSpeaker` + `SpeechBubblePresenter`) หางชี้หัว พลิก/เลื่อนเองเมื่อหัวชิดขอบหรือหลุดจอ บับเบิลไม่หลุดจอ **สัญลักษณ์เหนือหัว NPC** โชว์ในระยะ ~10 ม.: `!` Task (มีเควสให้รับ/ถ่ายรูปเควสมาแล้วพร้อมส่ง), `?` Other (ถ่ายรูปสิ่งอื่นที่ NPC ยังไม่เคยเล่า), `…` Talk (ไม่มีอะไร แค่คุยเล่น) เข้าระยะคุยได้จะเป็นวงกลมขาวบอกปุ่มกดคุย ("E") แล้วไอคอนย่อไปอยู่วงกลมเล็กมุมขวาบน (`NPCStatusIndicator`), ระหว่างคุยกดปุ่มไหนก็ได้/คลิกซ้ายเพื่อเดินบทต่อ — **NPC ย้ายจุดได้**: ผู้เล่นเดินห่างไปไกลและกลับมา NPC อาจอยู่จุดอื่น (สุ่มจากจุดที่วางไว้ ย้ายตอนผู้เล่นไม่เห็น เริ่มเกมอยู่จุดแรกเสมอ) `NPCRelocator` ตัวหนังสือขึ้นพร้อมเสียงพูดสุ่ม Pitch |
| **Photo Storage (คลังภาพ)** | เก็บรูปทั้งหมดที่ถ่ายไว้เป็นไฟล์บนดิสก์ (อยู่ข้ามการปิดเกม) ดูย้อนหลัง/ลบทิ้งได้ มีจำกัดจำนวนสูงสุด — หน้าคลังภาพและ Journal โชว์เป็น **รูปย่อ** (สร้างตอนถ่าย) เปิดแล้วไม่กระตุก ภาพเต็มโหลดตอนกดขยายดูเท่านั้น (รองรับ "โหมดเลือกภาพ" ให้ระบบอื่นเรียกใช้ เช่น Photo Board) |
| **Photo Board (บอร์ดแขวนรูป)** | Prefab บอร์ดวางได้หลายจุดในโลก แขวนรูปได้ 5 ช่องต่อบอร์ด เดินเข้าใกล้กด E เข้าหน้าบอร์ด (ตัวละครหยุดขยับเหมือน Pause) ช่องว่างกดแล้วเปิด Storage มาเลือกรูป ช่องที่มีรูปกดดูขยาย+ปุ่มลบ/เปลี่ยนรูป รูปที่แขวนยังอยู่ใน Storage ตามเดิม (แขวนซ้ำหลายบอร์ดได้ ลบจาก Storage แล้วช่องว่างตาม) และโชว์รูปจริงบนบอร์ดในโลก 3D ด้วย ไม่ใช่แค่ในเมนู |
| **Audio** | ระบบเสียงกลาง เรียกเล่นเสียงสั้นๆ (SFX) ได้จากทุกที่ในเกมโดยไม่ต้องมี AudioSource ของตัวเอง มี Mixer หลัก (Music/Ambient/SFX/UI ปรับความดังแยกกลุ่มได้) และ **โดมเสียงบรรยากาศ**: สุ่มเสียงนก/ใบไม้/แมลง/ลมเป็นจุด 3D รอบตัวผู้เล่น แยกกลางวัน-กลางคืนและพื้นผิว (ตอนนี้ใช้เสียงจำลอง รอไฟล์จริง) — **เสียงแม่น้ำ**: เดินเข้าใกล้แม่น้ำได้ยินเสียงน้ำไหลจากทิศของแม่น้ำ (`WaterAmbience`) — **เสียงเท้าสัตว์**: กวาง/มูสมีเสียงฝีเท้า 3D ชุดเดียวกับผู้เล่น (หญ้า/ดิน/ลุยน้ำ) มูสก้าวยาวกว่า เสียงทุ้มและดังกว่า (`CreatureFootsteps`) — **สัญลักษณ์ ! ตอนสัตว์เกิด**: ขึ้นเหนือหัวสัตว์บนจอแล้วเฟดหายใน 5 วิ ถ้าสัตว์อยู่นอกจอจะไปติดขอบจอฝั่งที่สัตว์อยู่และขยับตามไปเรื่อยๆ (`SpawnIndicatorUI`) |
| **Environment / Terrain Spawning** | แปลงต้นไม้ที่ปลูกด้วยเครื่องมือ Terrain ให้กลายเป็น GameObject จริง (เพื่อให้ถ่ายรูป/ชนได้) — มีเมนู Editor สร้างสนามทดสอบ NavMesh อัตโนมัติด้วย (`Tools > Photo Project > Generate NavMesh Test Environment`) — สร้างพื้น Terrain มีเนิน/ภูเขา + ต้นไม้สุ่ม + วางกวางกับ Player ให้พร้อมกด Play |
| **Day/Night Cycle** | ไล่เวลา เปลี่ยน Skybox/แสง/หมอกตามช่วงเวลา — ล็อคไว้ช่วงเดียวได้ (เช่นกลางวันตลอด) โดยตั้ง Start Hour + Time Scale = 0 — **นอนบนเตียงในบ้าน** (กด E) จอเฟดดำแล้วข้ามไปช่วงถัดไป เช้า 8 → เย็น 17 → กลางคืน 20 → เช้าวันใหม่ (กดจากนอกผนังบ้านไม่ได้) |
| **Debug Tools** | ปุ่มลัดสำหรับทดสอบ (ปุ่ม R ลบเซฟทั้งหมดแล้วกลับไป Main Menu, UI โชว์เควสที่ Active อยู่มุมซ้ายบน, ปุ่ม **AI State / Detail** บน Scene view โชว์ State ของสัตว์ทุกตัวเหนือหัว) — ใช้ตอน Playtest เท่านั้น — กล้องบินอิสระ **F8** สำหรับอัดวิดีโอ (ใช้คู่กับ Unity Recorder) และสั่งสัตว์ใกล้กล้อง **F5** กินหญ้า / **F6** เดินไปจุดที่เล็ง / **F7** ยืนนิ่ง / **F9** คืนให้ AI |
| **World HUD** | ไอคอนกลาง + ปุ่ม 4 ทิศ (Storage/Camera/Journal/Map) มุมซ้ายล่าง โชว์เฉพาะตอนเดินสำรวจ ปิดหมดทันทีที่เปิด UI อื่น — ปุ่ม Map ยังไม่มีระบบรองรับ |
| **ฟอนต์** | ตัวหนังสือทุกตัวในเกม (Journal, HUD, Pause, บับเบิลคำพูด, ป้ายต่าง ๆ) ใช้ฟอนต์ **Itim** (`[01]Art/Ui Elements/Font`) และตั้งเป็นฟอนต์ตั้งต้นของ TextMesh Pro แล้ว (Text ที่สร้างใหม่ได้ Itim เอง) — ⚠️ `Itim-Regular SDF` มีแค่ตัวอักษรอังกฤษ ข้อความไทยใช้ `Itim-Regular Thai SDF` (ไทย + อังกฤษ, Static) แทน — ตอนนี้ใช้แค่ในป๊อปอัป Reset ของเมนูหลัก |
| **Pause & Setting** | กด Esc (เฉพาะตอนเดินปกติ ถ่ายรูป/คุย NPC ไม่เปิด) = หยุดเกม ฉากหลังเบลอ มีปุ่ม Resume / Setting / Back to Menu (กลับเมนูโดยเก็บความคืบหน้าไว้) — Setting ปรับเสียง Master / Ambient / Music / Sound Effect ด้วย Slider หรือพิมพ์ตัวเลข 0-100 เซฟข้ามการเปิดเกม — ถ้าเปิด Journal/Storage/บอร์ดอยู่ Esc ย้อน/ปิดหน้านั้นก่อน |
| **Main Menu** | Scene แยกต่างหาก มีปุ่ม Play (โหลด `PlayTest_Final`) กับ Exit เป็นแคปซูลขาวขอบเข้ม ฟอนต์ Itim ขยายนิดๆ ตอนเอาเมาส์วาง โลโก้เกม Vista: A forest wanderer อยู่ด้านบน ฉากหลังเป็นทุ่งหญ้ามีเนินและบ่อน้ำ ล้อมด้วยต้นไม้ — **ปุ่ม Reset** วงกลมมุมขวาล่าง (ไอคอนลูกศรวนเป็น Placeholder) กดแล้วขึ้นป๊อปอัปเตือนภาษาไทยกลางจอ ยืนยัน = ลบรูปและความคืบหน้าทั้งหมด / ยกเลิก = ปิด |
| **Prefab หลักข้ามซีน** | ซีนใหม่ลากแค่ 3 อัน: `PlayerRig` (ผู้เล่น + กล้อง + HUD), `GameSystems` (เวลา, บทสนทนา, เสียงประกอบ), `AudioManager` (ระบบเสียงที่อยู่ข้ามซีน) — ของที่ผูกกับแมพ (Terrain, กระท่อม, NPC, โหนด AI, Spawner) ยังอยู่ในซีนตามเดิม |

## แผนที่โฟลเดอร์ (Script/)

```
Player/      — การเคลื่อนที่, State Manager, Debug Reset
Camera/      — กล้อง, ระบบถ่ายรูป (Photograph/)
Creature/    — ข้อมูลสัตว์/พืช (Profile) + AI (AI/)
Journal/     — สมุดบันทึก
Quest/       — เควส + NPC + Debug UI
Storage/     — คลังภาพ + SaveSystem (เซฟ/โหลด JSON)
PhotoBoard/  — บอร์ดแขวนรูปในโลก 3D
Audio/       — ระบบเสียง
EnviromentScript/ — สร้างต้นไม้จาก Terrain
MainMenu/    — เมนูหลัก (Start/Exit/Reset)
House/       — ของในบ้าน (เตียงนอนข้ามเวลา)
UI/          — HUD กลางจอ
```

# The Photo Project — สรุประบบทั้งหมด (ย่อ)

>
> **อัปเดตล่าสุด:** 2026-09-15

## เกมนี้คืออะไร

เกมสำรวจธรรมชาติมุมมองบุคคลที่ 1/3 — เดินสำรวจป่า **ถ่ายรูป** สัตว์/พืชที่เจอ เก็บเข้า **สมุดบันทึก (Journal)** และคุยกับ **NPC** เพื่อรับ/ส่งเควส

## ระบบหลักที่มีอยู่ตอนนี้

| ระบบ | ทำอะไร |
|---|---|
| **State Manager** | ตัวกลางคุม "สถานะเกม" (เดินปกติ/ถ่ายรูป/คุย NPC/เปิด Journal/เปิด Storage/พัก) ระบบอื่นทุกระบบเช็คจุดนี้ก่อนว่าตอนนี้ทำอะไรได้บ้าง |
| **Player Movement & Camera** | เดิน/วิ่ง/กระโดด/ย่อ พร้อม Foot IK (เท้าเหยียบพื้นจริง) และกล้องบุคคลที่ 3 แบบสลับไหล่ซ้าย-ขวาได้ |
| **Photography (ถ่ายรูป)** | กดเข้าโหมดถ่ายรูป เล็งเป้า ซูมเข้า-ออก กดชัตเตอร์ถ่าย แล้วบันทึกเป็นไฟล์ภาพ พร้อมเช็คว่าถ่ายติดสัตว์/พืชตัวไหนบ้าง |
| **Creature AI (พฤติกรรมสัตว์)** | สัตว์มี AI แบบ Behavior Tree: เดินเล่น (Idle/Walking) → ตกใจเมื่อเห็น/ได้ยินผู้เล่น (Alert) → วิ่งหนี (Run) หลบในท่าย่อจะทำให้สัตว์มองเห็นเราได้ยากขึ้น |
| **Journal (สมุดบันทึก)** | แคตตาล็อกของสิ่งมีชีวิตทั้งหมด แบ่งหมวดพืช/สัตว์ ก่อนถ่ายรูปโชว์แค่เงาดำ+ที่อยู่ ถ่ายติดแล้วปลดล็อกรูปจริง ส่วนคำอธิบายโชว์ต่อเมื่อกลับไปคุยกับ NPC จนได้ฟังเรื่องนั้นแล้วเท่านั้น (เหมือนจดความรู้จาก NPC ลงสมุด) |
| **Quest & Dialogue** | คุยกับ NPC ผ่านระบบ Yarn Spinner รับเควส "ไปถ่ายรูป X มา" กลับมาคุยอีกครั้งเพื่อส่งเควส |
| **Photo Storage (คลังภาพ)** | เก็บรูปทั้งหมดที่ถ่ายไว้เป็นไฟล์บนดิสก์ ดูย้อนหลัง/ลบทิ้งได้ มีจำกัดจำนวนสูงสุด |
| **Audio** | ระบบเสียงกลาง เรียกเล่นเสียงสั้นๆ (SFX) ได้จากทุกที่ในเกมโดยไม่ต้องมี AudioSource ของตัวเอง |
| **Environment / Terrain Spawning** | แปลงต้นไม้ที่ปลูกด้วยเครื่องมือ Terrain ให้กลายเป็น GameObject จริง (เพื่อให้ถ่ายรูป/ชนได้) |
| **Debug Tools** | ปุ่มลัดสำหรับทดสอบ (รีเซ็ตเกมทั้งหมดด้วยปุ่ม R, UI โชว์เควสที่ Active อยู่มุมซ้ายบน) — ใช้ตอน Playtest เท่านั้น |

## แผนที่โฟลเดอร์ (Script/)

```
Player/      — การเคลื่อนที่, State Manager, Debug Reset
Camera/      — กล้อง, ระบบถ่ายรูป (Photograph/)
Creature/    — ข้อมูลสัตว์/พืช (Profile) + AI (AI/)
Journal/     — สมุดบันทึก
Quest/       — เควส + NPC + Debug UI
Storage/     — คลังภาพ
Audio/       — ระบบเสียง
EnviromentScript/ — สร้างต้นไม้จาก Terrain
```
